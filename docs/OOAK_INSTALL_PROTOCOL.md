# OOAK :: INSTALLATION EDITION — PROTOCOL

## PRE-SALE SETUP QUESTIONNAIRE
1. What will the work display on? (TV / projector / monitor / tablet)
   Brand + model if known, or a PHOTO of the device and its ports.
2. Does it have a built-in browser, OR can we plug a device into its HDMI?
3. Is there wifi at the location? Name of network available on install day?
4. Where does it live — wall, shelf, window? Rough photo of the spot.
5. Power outlet within reach of the spot? Extension needed?
6. City/area (for travel) — or is remote install acceptable?
7. Who will be present on install day / who dusts it and turns it on after?

**RULE: no install date until answers arrive.**
