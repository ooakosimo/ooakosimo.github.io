the work ::

A procession of shadow creatures walking through a slow photographic melt — decay as a medium, attention as a signal. Pilots steer the procession from their phones and flash their names briefly across the wall: present a moment, then surrendered to the melt, like everything else. Descends from the artist's shadow practice (2017), blessed by name by Marko Zubak, a.k.a. Mlibty.

the house ::

the work ::

An origami flock in four dusk palettes — cranes, planes, torn scraps sharing one sky. Untouched they drift; something unseen spooks them — ripple, scatter, regroup. Nobody dies, nobody wins, life continues. The sky heals without scars; the only memory of the panic lives in you. Descends from Craig Reynolds' boids (1986) — flocking born from watching real crowds.

the record ::

MEDIUM :: interactive browser-based flock — single hand-coded HTML file (JavaScript/p5.js); mouse & touch
DIMENSIONS :: variable — resolution-independent
DURATION :: continuous — a full dusk cycle every ~4 minutes; never the same flight twice
ADDRESS :: ooakosimo.neocities.org/dusk
